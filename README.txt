MUSIC ALBUM GALLERY

Contains 130 album covers.

PREVIEW: Open index.html in your web browser.

PUBLISH ON GITHUB PAGES:
1. Create a PUBLIC GitHub repository (for example, music-albums).
2. Upload ALL the contents of this folder to the repository ROOT:
   index.html, style.css, gallery.js, albums.json, images/, thumbs/.
3. In repository Settings > Pages, choose Deploy from a branch.
4. Choose main and /(root), then Save.
5. The public URL will be https://YOUR-USERNAME.github.io/music-albums/

All images are hosted with the site. No Dropbox or backend is needed.
To update the gallery, provide an updated image ZIP and regenerate this site.

Albums are numbered sequentially in alphabetical order, both in the gallery and in JPG filenames.
The site is responsive, with two album covers per row on smartphones.
